# One Line, One Laugh

A tiny deterministic program that writes exactly one original funny line to
`/output/entry.txt` — a joke about what your phone's screen time report
really means.

## Run

```sh
node main.ts
```

This writes a single line (under 200 characters) to `/output/entry.txt`.
